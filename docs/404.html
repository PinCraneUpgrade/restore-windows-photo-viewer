What the tool does, and what it leaves alone

Windows Photo Viewer never left Windows. Microsoft hid it after Windows 8. This tool makes it selectable again.

Restore Windows Photo Viewer with one click

The tool applies the small set of registry changes that make Photo Viewer a default app option again and adds it back to the Open with menu.

  • Choose which formats it opens: JPEG, BMP, PNG, TIFF, WDP, GIF
  • Apply it just for you or for all users on the computer
  • Your photos aren’t moved, changed or deleted

Undo anytime, switch back to Photos app

Changed your mind? Open the tool again and click Keep using Photos App. Windows goes back to opening pictures in Photos, the way it was before.

Nothing is uninstalled either way, so switching back and forth is safe.

Keep using Photos App reverses every change Restore made.

Why not just edit the registry manually?

The fix itself is a handful of registry keys. There are three ways to apply them, and they ask very different things of you.

This app Manual .reg file Editing registry by hand
No risk of typos Yes Only if the file is right One wrong value breaks it
One-click undo Yes Needs a second undo file Revert each key yourself
No tech knowledge needed Yes You merge a file you can’t read Requires regedit
Choose file types and users Checkboxes Fixed in the file If you know the keys

Most download sites hand out a bare .reg file. This app applies the same fix, shows you what it covers, and gives you a way back.

Questions before you download

Can’t find your answer? Open an issue on GitHub.

Is it safe to use?

Yes. The tool only changes which app Windows treats as the default photo viewer. It doesn’t modify or delete any of your photos, and the change can be undone at any time from within the app.

Does it work on Windows 11?

Yes. Restore Windows Photo Viewer works on both Windows 10 and Windows 11, including the latest updates.

Why is Windows Photo Viewer not in my default apps list?

Starting with Windows 8, Microsoft hides Windows Photo Viewer from the default apps settings, even though the program files are still included in Windows. This tool re-enables it without removing or reinstalling anything.

Can I switch back to the Photos app later?

Yes. Open the tool again and click Keep using Photos App. Windows goes back to opening pictures in the Photos app.

Do I need admin rights?

Yes. Because it changes system default app settings, the tool needs administrator rights. If it doesn’t ask automatically, right-click the .exe and choose Run as administrator.
